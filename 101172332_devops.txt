Course Overview - COMP 3104 (DevOps):
COMP 3104 is an advanced computing course focusing on bridging software development and IT operations through modern 
practices and tools.

Core Concepts and Topics:

Version Control & Collaboration: Managing source code with Git and GitHub, applying branching strategies, 
and resolving merge conflicts.

Continuous Integration & Continuous Deployment (CI/CD): Automating build, testing, and deployment 
pipelines using GitHub Actions or Travis CI.

Infrastructure & Automation: Ensuring repeatable deployments, automated testing, and system monitoring to 
minimize human error.

Collaboration Culture: Driving teamwork via code reviews, pull request workflows, and clear project documentation.
